SISTEMA PARA CADASTRO, GERENCIAMENTO E EMPRÉSTIMO DE LIVROS

Refazendo um projeto antigo que tinha feito usando appscript, mas agora utilizando tecnologias melhores e mais atuais

Funcionalidades:
-Cadastro de Livros para o banco de dados
-Remoção dos Livros do Banco
-Realização de Emprestimos dos Livros
-Modais de aviso sobre a data de entrega
-Cadastro da pessoa com o Livro que ela pegou
-Retirada da pessoa da tabela depois da devolução do Livro
